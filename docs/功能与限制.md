# 功能与限制

一页看清能做什么、做到什么程度、边界在哪。算子的逐条细节见《算子参考》，与 ggml 的对照见《兼容性》。

## 0. 一分钟总览

**能：**

- 训练：自动求导、SGD / AdamW、学习率调度、梯度累积与裁剪、常用网络层与损失。
- 多后端：CPU 参考后端 + Vulkan 后端，同一份代码跨设备运行。
- 模型：导出 GGUF（ggml 生态可加载）；读取含常见量化的 GGUF 做热启动。
- 训练状态：checkpoint 保存参数 + 优化器状态 + 随机数 + 调度器，断点续训与不中断训练逐位一致。
- 工程：CMake 集成；库本体无第三方依赖（Vulkan 后端仅依赖 Vulkan SDK）。

**不能（当前版本）：**

- 混合精度训练（AMP）、量化训练、量化导出。
- 分布式 / 多卡训练、梯度检查点、flash attention、融合反向 kernel。
- `out_prod`。
- K-quant / IQ 等量化格式读取、大端平台。
- 动态后端插件（DLL）、C ABI、Python 绑定。
- 具体模型结构与数据预处理管线。

## 1. 平台与后端

| 后端 | 状态 | 计算精度 | 要求 |
|---|---|---|---|
| CPU | 完整 | F32 | 无 |
| Vulkan | 完整 | F32（F16 可存储/转换） | Vulkan 1.2+；F32↔F16 需 `storageBuffer16BitAccess` |

- 设备选择：`device_count` / `device_get` / `device_by_type` / `device_cpu`；Vulkan 可用 `TRC_VK_DEVICE` 指定设备、`TRC_VK_VALIDATE=1` 开校验层。
- 能力查询：`supports_op` 是唯一门控；训练前可用 `graph_first_unsupported` 预检整图。
- 当前验证平台：Windows 11 + MSVC；核心为可移植 C++20。

## 2. 数据类型

| 类型 | 存储 | CPU 计算 | Vulkan 计算 |
|---|---|---|---|
| F32 | 支持 | 全部算子 | 全部受支持算子 |
| F16 | 支持 | 部分输入（`cast`、`get_rows` 表、`set_rows` 值、`im2col` 图像、`soft_max` mask） | `cast` F32↔F16（需 16 位存储） |
| BF16 / F64 / I8 / I16 / I32 / I64 | 支持（存储/转换） | 仅 `cast`；I32/I64 可作索引 | 不支持（I32 可作索引） |
| Q4_0 / Q4_1 / Q5_0 / Q5_1 / Q8_0 | 仅读取 | 反量化为 F32 | — |
| K-quant / IQ 等 | 不支持 | — | — |

- `tensor_set/get` 为字节语义；非连续视图需先 `cont()`。
- 视图不支持量化类型；视图必须在其源张量之后创建。
- `sum` / `sum_rows` 结果类型同输入；`mean` 固定 F32。

## 3. 算子

算子的完整清单、签名、约束与各后端支持矩阵见《算子参考》。汇总：

- 形状：视图、`reshape`、`permute` / `transpose`、`cont`、`cast`、`dup`。
- 逐元素与激活：二元四则、`add1`、一元数学、`clamp`、`scale` / `scale_bias`、`relu` / `leaky_relu` / `sigmoid` / `tanh_op` / `silu` / `gelu` / `gelu_erf` / `erf_op` / `softplus` / `hardswish`。
- 归约与归一化：`sum` / `sum_rows` / `mean`、`norm` / `rms_norm` / `group_norm`（含反向）。
- 注意力：`soft_max` / `soft_max_ext`（scale、mask、ALiBi）。
- 索引：`get_rows` / `get_rows_back` / `set_rows`。
- 形状扩展：`repeat` / `repeat_back` / `concat` / `pad` / `pad_ext`（零填充与 reflect）/ `pad_back` / `acc`。
- 卷积与池化：`im2col` / `im2col_back` / `conv_1d` / `conv_2d` / `col2im_1d` / `conv_transpose_1d` / `conv_transpose_2d` / `pool_2d` / `pool_2d_back`。
- 线代与损失：`mul_mat`、`cross_entropy_loss` / `cross_entropy_loss_back`。

## 4. 自动求导

- 反向 = 前向算子组合，追加进同一图；一次 compute 完成前向与反向。
- 已支持反向的算子清单见《自动求导与训练》§8。
- 梯度 inplace 累加进持久累加器；每步必须 `graph_reset`。
- 多图共享参数 / 梯度路径中间量为构建期禁止；双图训练用冻结 / 解冻 + detach 输入。
- 同一图不可重复展开反向。

## 5. 训练组件

- 优化器（主机端）：SGD、AdamW，对齐 PyTorch；支持参数分组与动态加组。
- 调度器：StepLR、ExponentialLR、CosineAnnealingLR、warmup + cosine。
- 梯度：累积（micro-batch）、全局 L2 裁剪。
- 随机数：splitmix64，确定性、可随 checkpoint 恢复。
- 权重初始化：constant / uniform / normal / kaiming。

## 6. 神经网络层

`Linear` / `Embedding` / `Conv1d`（分组）/ `Conv2d` / `ConvTranspose1d` / `WeightNorm` / `LayerNorm` / `RmsNorm` / `GroupNorm` / `Dropout`。权重布局 = PyTorch `state_dict`。详见《神经网络层》。

## 7. 损失

`mse_loss` / `l1_loss`（全元素均值）、`cross_entropy_loss`（同形状概率目标）。详见《损失函数》。

## 8. 模型与训练状态 I/O

- GGUF 写出：v3、32 字节对齐；原类型或 F32→F16；不量化。
- GGUF 读取：v2 / v3；支持基本类型与 5 种 legacy 量化反量化。
- checkpoint：恒写 schema v2，读兼容 v1；支持多优化器分区。

## 9. 数值与精度

| 项目 | 说明 |
|---|---|
| 计算精度 | 统一 F32 计算（无 AMP）；F16 仅存储 / 转换 |
| 归约累加 | CPU 用 double；Vulkan 用 float 分层归约（超长行可能有约 1e-5 差异） |
| `erf` | Vulkan 用 Abramowitz-Stegun 7.1.26 近似（与 ggml Vulkan 同系数） |
| F16 转换 | 位级算法与 ggml 一致（含次正规数） |
| 索引越界 | CPU 与 Vulkan 均明确中止，不静默 |
| 能力预检 | `graph_first_unsupported` 返回首个不支持节点；`supports_op` 如实声明 |
| 设备上限 | 显式校验单缓冲 / 单次分配 / descriptor range，超限中止并打印“需要 / 上限” |
| 图级复用 | `buffer_alloc_graph_tensors` 按执行序复用中间量；**compute 后读取中间量需标 `TENSOR_FLAG_OUTPUT`** |
| 反复建图 | `context_release_graph_tensors` 回收中间量；张量元数据不回收 |

## 10. 明确不支持清单（负向清单）

**功能类**：混合精度（AMP）；量化训练与量化导出；分布式训练；梯度检查点；flash attention；融合反向 kernel；动态后端插件；C ABI；Python 绑定；具体模型结构与数据预处理；权重格式转换工具。

**算子 / 语义类**：`out_prod`；`set_rows` 反向；`col2im_1d` 反向；`conv_transpose_1d` 的 `p0≠0` / `d0≠1`；`conv_transpose_2d` 的 padding / dilation / output_padding；`pool_2d_back` 的 Vulkan 实现；量化类型参与计算；`soft_max_ext` 的 sinks；交叉熵的整数类别标签；K-quant / IQ 读取；大端 GGUF；`repeat` 前向的整数倍广播（仅支持每维相等或为 1；`repeat_back` 支持整除）。

**后端差异（Vulkan 比 CPU 窄）**：`cast` 仅 F32↔F16；`get_rows` 表仅 F32；索引仅 I32；`set_rows` 值仅 F32；`soft_max` mask 仅 F32；`im2col` 图像仅 F32；`dup` / `cont` / `pad` / `repeat` / `concat` / `acc` 仅 F32；`pool_2d_back` 无实现。

**性能类**：CPU 无 SIMD 特化；Vulkan 计算缓冲默认 host-visible（系统内存），无 staging / 内存池、无 pipeline cache；默认单命令缓冲一次提交（可用 `TRC_VK_CHUNK_NODES` 分块）；`get_rows_back` 为 O(n_vocab×nr)；无多队列 / 重叠。

**平台 / 工程类**：GGUF 仅小端；Vulkan 后端依赖 Vulkan SDK；`VK_ERROR_DEVICE_LOST`（TDR / 驱动重置）进程内不可恢复；验证平台为 Windows + MSVC；无版本管理接口；线程安全未承诺（Context / Graph / Device 勿跨线程并发使用）。

## 11. 适用与不适用

**适合**：中小规模模型的 CPU / Vulkan 训练与微调；训练产物需要直接进入 ggml 推理生态；无 CUDA 环境；需要可嵌入、可审计的 C++ 训练内核。

**暂不适合**：需要混合精度 / 量化训练的大模型；需要高吞吐融合 kernel 的场景；需要读取任意量化格式（K-quant / IQ）做微调；依赖 Python 训练脚本的场景。
