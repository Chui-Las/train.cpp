# 优化器与调度

优化器在主机端实现，通过 `tensor_get` / `tensor_set` 读写参数与梯度，因此与后端无关（CPU / Vulkan 通用）。数值语义对齐 PyTorch `torch.optim.SGD` / `torch.optim.AdamW`。

## 1. 创建优化器

```cpp
ParamList params;
linear_params(&fc1, &params);
linear_params(&fc2, &params);

AdamwOptions o;
o.lr = 1e-3f;
o.weight_decay = 1e-2f;
Optimizer* opt = optim_adamw_new(ctx, params.items.data(), param_list_count(&params), o);
```

SGD 同理：

```cpp
SgdOptions so;
so.lr = 0.01f;
so.momentum = 0.9f;
Optimizer* opt = optim_sgd_new(ctx, params.items.data(), n_params, so);
```

参数约束：**F32、连续、非视图**。层初始化函数（`*_init`）产生的权重满足这些条件。

## 2. 选项与公式

### SGD（`SgdOptions`）

| 字段 | 默认 | 说明 |
|---|---|---|
| `lr` | `1e-2` | 学习率 |
| `momentum` | `0.0` | 动量 |
| `dampening` | `0.0` | 动量阻尼 |
| `weight_decay` | `0.0` | 权重衰减（L2 形式） |
| `nesterov` | `false` | Nesterov 动量 |

更新：`d_p = g + weight_decay·p`；有动量时 `buf = momentum·buf + (1-dampening)·d_p`（首个动量步直接取 `d_p`），`nesterov ? d_p = d_p + momentum·buf : d_p = buf`；`p -= lr·d_p`。

### AdamW（`AdamwOptions`）

| 字段 | 默认 | 说明 |
|---|---|---|
| `lr` | `1e-3` | 学习率 |
| `beta1` | `0.9` | 一阶矩衰减 |
| `beta2` | `0.999` | 二阶矩衰减 |
| `eps` | `1e-8` | 数值稳定项 |
| `weight_decay` | `1e-2` | 解耦权重衰减 |

更新：`p *= 1 - lr·weight_decay`；`m = b1·m + (1-b1)·g`；`v = b2·v + (1-b2)·g²`；`p -= lr·(m/(1-b1^t)) / (sqrt(v/(1-b2^t)) + eps)`。

## 3. 参数分组

同一优化器内可包含多组参数，组间超参独立，步数统一计数：

```cpp
Optimizer* opt = optim_adamw_new(ctx, group0, n0, AdamwOptions{.lr = 1e-3f});
optim_add_param_group_adamw(opt, group1, n1, AdamwOptions{.lr = 1e-4f});  // 训练中也可动态加组
```

新组的状态在首次 `optim_step`（或 `optim_alloc_state`）时自动分配。查询：

```cpp
int64_t groups = optim_group_count(opt);
int64_t total  = optim_param_count(opt);
Tensor*  p     = optim_param(opt, index);          // 按 组→参数 顺序
OptimType t    = optim_group_type(opt, group);     // OptimType::SGD / ADAMW
float    lr    = optim_get_lr_group(opt, group);
```

注意：**单个优化器内不支持组间混合类型**（同一优化器不能既有 SGD 组又有 AdamW 组）。需要混合时使用两个优化器。

## 4. 状态

- SGD 每个参数一个状态张量（`momentum`）；AdamW 每个参数两个（`m`、`v`）。
- 状态在首次 `optim_step` 自动分配；断点续训前可显式分配：

```cpp
optim_alloc_state(opt);
int64_t n = optim_state_count(opt);
Tensor* s = optim_state(opt, index);
```

状态以 F32 张量暴露，可随 checkpoint 序列化（见《断点续训》）。

## 5. 训练循环

```cpp
for (int step = 0; step < n; ++step) {
    graph_reset(g);
    dev->graph_compute(g);
    optim_step(opt);          // 读取 t->grad / t->grad_acc 更新参数
}
```

相关操作：

```cpp
optim_zero_grad(opt);                    // 清零全部参数梯度（也可用 graph_reset）
float pre = optim_clip_grad_norm(opt, 1.0f);   // 全局 L2 裁剪，返回裁剪前范数
int64_t c = optim_step_count(opt);       // 已执行步数
```

## 6. 学习率调度

调度器以优化器**第 0 组**的学习率为基准；每次 `lr_scheduler_step` 推进一次并把新学习率写回优化器。

```cpp
LrScheduler* s = lr_scheduler_cosine_new(opt, /*t_max=*/1000, /*eta_min=*/0.0f);

for (int step = 0; step < n; ++step) {
    graph_reset(g);
    dev->graph_compute(g);
    optim_step(opt);
    lr_scheduler_step(s);          // 返回新学习率
}
float lr = lr_scheduler_get_lr(s); // 当前学习率
int64_t e = lr_scheduler_epoch(s); // 已推进次数
```

可用调度器：

| 创建函数 | 语义 |
|---|---|
| `lr_scheduler_step_new(opt, step_size, gamma)` | 每 `step_size` 次 step 后 `lr *= gamma` |
| `lr_scheduler_exponential_new(opt, gamma)` | 每次 step 后 `lr *= gamma` |
| `lr_scheduler_cosine_new(opt, t_max, eta_min)` | 余弦退火；`t > T_max` **不截断**（与 PyTorch 一致） |
| `lr_scheduler_warmup_cosine_new(opt, warmup_steps, total_steps, eta_min)` | 线性 warmup + 余弦退火（本库扩展） |

`lr_scheduler_free` 释放调度器。

## 7. 与 PyTorch 的对照

| 本库 | PyTorch |
|---|---|
| `SgdOptions` | `torch.optim.SGD` |
| `AdamwOptions` | `torch.optim.AdamW`（解耦权重衰减） |
| `lr_scheduler_step_new` | `StepLR` |
| `lr_scheduler_exponential_new` | `ExponentialLR` |
| `lr_scheduler_cosine_new` | `CosineAnnealingLR` |
| `lr_scheduler_warmup_cosine_new` | 无直接对应（LambdaLR 常用实现） |

优化器轨迹（含 AdamW 的 bias correction）与 PyTorch 逐位对齐，可用于从 PyTorch 迁移训练脚本。

## 8. 断点续训相关接口

以下接口主要用于 checkpoint 序列化，正常训练无需直接调用：

```cpp
optim_set_step_count(opt, step);                      // 恢复全局步数
int64_t ps = optim_state_step(opt, param_index);      // 每参数状态步数
optim_set_state_step(opt, param_index, ps);
optim_group_sgd_options(opt, group);                  // 读取组超参
optim_group_adamw_options(opt, group);
```

详见《断点续训》。
