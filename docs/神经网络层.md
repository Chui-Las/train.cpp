# 神经网络层

层是纯数据结构（POD struct + 自由函数）：结构体持有参数张量与超参，前向由已有算子组合实现。权重张量的 `ne` 顺序是 PyTorch 形状的反序，与 `state_dict` 一一对应，便于 GGUF 互通。

## 1. 通用用法

层的 `*_init` / `*_init_weight` 会**自动把参数标记为可训练**（`TENSOR_FLAG_PARAM`），常规训练只需收集 `ParamList` 交给优化器：

```cpp
Rng rng;
rng_seed(&rng, 1234);

Linear fc1{}, fc2{};
linear_init(ctx, &fc1, /*in=*/4, /*out=*/8, /*use_bias=*/true, &rng, "fc1");
linear_init(ctx, &fc2, 8, 1, true, &rng, "fc2");

ParamList params;
linear_params(&fc1, &params);
linear_params(&fc2, &params);

Tensor* h    = relu(ctx, linear_forward(ctx, &fc1, x));
Tensor* pred = linear_forward(ctx, &fc2, h);
```

参数收集后按《自动求导与训练》的流程训练。

## 2. 各层

### 2.1 Linear

```cpp
Tensor* y = linear_forward(ctx, &layer, x);
```

- 权重 `W=[in, out]`、偏置 `b=[out]`（可选）；`x=[in, batch]` → `[out, batch]`。
- 初始化：kaiming_uniform(a=√5)，bias 为 ±1/√fan_in 均匀分布（与 PyTorch 一致）。

### 2.2 Embedding

```cpp
Embedding emb{};
embedding_init(ctx, &emb, /*num_embeddings=*/1000, /*embedding_dim=*/16, &rng, "emb");
Tensor* y = embedding_forward(ctx, &emb, indices);   // indices 必须为 I32
```

- 权重 `W=[dim, n_vocab]`；索引张量类型为 `TYPE_I32`。
- 初始化：N(0,1)。

### 2.3 Conv1d

```cpp
Conv1d c{};
conv1d_init(ctx, &c, /*ic=*/4, /*oc=*/8, /*k=*/3, /*stride=*/1, /*padding=*/1,
            /*dilation=*/1, /*use_bias=*/true, &rng, "conv1");
// 输入 x=[W, IC, N]，输出 [OW, OC, N]
Tensor* y = conv1d_forward(ctx, &c, x);
```

分组卷积：

```cpp
conv1d_init_groups(ctx, &c, /*ic=*/16, /*oc=*/32, 3, 1, 1, 1, /*groups=*/4, true, &rng, "conv1g");
```

- 权重 `[KW, IC/groups, OC]`；`in/out` 通道都必须被 `groups` 整除。
- 前向按组切片后沿 `ne1` 拼接，自动反传。

### 2.4 Conv2d

```cpp
Conv2d c{};
conv2d_init(ctx, &c, /*ic=*/3, /*oc=*/16, /*kw=*/3, /*kh=*/3, /*sw=*/1, /*sh=*/1,
            /*pw=*/1, /*ph=*/1, /*dw=*/1, /*dh=*/1, true, &rng, "conv2");
// 输入 x=[W, H, IC, N]，输出 [OW, OH, OC, N]
Tensor* y = conv2d_forward(ctx, &c, x);
```

- 权重 `[KW, KH, IC, OC]`。
- 暂无分组字段。

### 2.5 ConvTranspose1d

```cpp
ConvTranspose1d ct{};
convtranspose1d_init(ctx, &ct, /*ic=*/4, /*oc=*/8, /*k=*/4, /*stride=*/2, /*padding=*/1,
                     /*dilation=*/1, true, &rng, "ct1");
// 输入 x=[T, IC, N]，输出 [T_out, OC, N]，T_out = (T-1)*stride - 2*padding + K
Tensor* y = convtranspose1d_forward(ctx, &ct, x);
```

- 权重 `[K, Cout, Cin]`（即 torch `(Cin, Cout, K)` 的反序）。
- 仅支持 `dilation=1`；`padding` 通过输出中心裁剪实现；层内支持任意 `N`（按样本切片后拼接）。

### 2.6 WeightNorm

`w = g · v / ‖v‖`（逐输出通道，等价 `torch.nn.utils.weight_norm(dim=0)`），组合实现、可反传。

```cpp
Tensor* v = new_tensor_2d(ctx, TYPE_F32, IN, OUT);
Tensor* g = new_tensor_2d(ctx, TYPE_F32, 1, OUT);
WeightNorm wn;
weightnorm_init(ctx, &wn, v, g, "fc");       // 自动标参
nn_init_kaiming_uniform(ctx, v, std::sqrt(5.0f), &rng);

Tensor* w = weightnorm_forward(ctx, &wn);    // 重参数化权重
Tensor* y = linear_forward_weight(ctx, &linear_layer, w, x);
```

- `v` 与被包装权重同形；`g` 在最后一维（输出通道）非 1、其余维为 1。
- buffer 分配后调用 `weightnorm_sync_g(&wn)` 令 `g = ‖v‖`（与 torch 初始化对齐，一次即可）。
- 便捷前向：`linear_forward_weight`、`conv1d_forward_weight`、`conv2d_forward_weight`、`convtranspose1d_forward_weight`。
- 分组卷积的 WeightNorm：`v` 建成 `[KW, IC/groups, OC]`、`g` 建成 `[1,1,OC]`，令层的 `groups` 与之一致，再用 `conv1d_forward_weight` 前向。

### 2.7 LayerNorm / RmsNorm / GroupNorm

```cpp
LayerNorm ln{};
layernorm_init(ctx, &ln, /*normalized_size=*/16, /*eps=*/1e-5f, /*use_bias=*/true, "ln");
Tensor* y = layernorm_forward(ctx, &ln, x);

RmsNorm rn{};
rmsnorm_init(ctx, &rn, 16, 1e-5f, "rn");
Tensor* yr = rmsnorm_forward(ctx, &rn, x);

GroupNorm gn{};
groupnorm_init(ctx, &gn, /*n_groups=*/8, /*num_channels=*/32, 1e-5f, true, "gn");
Tensor* yg = groupnorm_forward(ctx, &gn, x);
```

- `LayerNorm`：沿 `ne0` 归一化，`weight/bias=[n]`（有偏方差）。
- `RmsNorm`：沿 `ne0`，无 bias，`weight=[n]`。
- `GroupNorm`：沿 `ne2`（通道维）分组，`weight/bias=[C]`，要求 `x.ne2 == num_channels`。
- 默认初始化：weight=1、bias=0。

### 2.8 Dropout

```cpp
Dropout drop;
dropout_init(&drop, /*p=*/0.1f, "drop");

dropout_set_training(&drop, true);
Tensor* y = dropout_forward(ctx, &drop, x);   // 训练：y = x * mask
// 每个训练步：graph_reset -> dropout_refresh -> graph_compute
dropout_refresh(&drop, &rng);

dropout_set_training(&drop, false);
Tensor* y_eval = dropout_forward(ctx, &drop, x);   // eval：恒等，返回输入本身
```

inverted dropout：mask 取值 `{0, 1/(1-p)}`，与输入同形、延迟创建。训练步序见《自动求导与训练》§7。

## 3. 初始化

```cpp
nn_init_constant(ctx, t, 1.0f);
nn_init_uniform(ctx, t, -1.0f, 1.0f, &rng);
nn_init_normal(ctx, t, 0.0f, 0.02f, &rng);
nn_init_kaiming_uniform(ctx, t, /*a=*/std::sqrt(5.0f), &rng);
int64_t fi = nn_fan_in(t);
int64_t fo = nn_fan_out(t);
```

`no_alloc=true` 时初始化会延迟到 `buffer_alloc_ctx_tensors` 之后执行；每个张量使用独立派生种子，结果与分配顺序无关、可复现。

## 4. 参数列表

```cpp
ParamList params;
linear_params(&fc1, &params);
conv1d_params(&conv, &params);
param_list_merge(&params, &other);          // 合并多个列表
int64_t n = param_list_count(&params);
Tensor* p = param_list_get(&params, 0);
param_list_set_param(&params, false);       // 冻结 / 解冻
```

层对应的收集函数：`linear_params`、`embedding_params`、`conv1d_params`、`conv2d_params`、`convtranspose1d_params`、`weightnorm_params`、`layernorm_params`、`rmsnorm_params`、`groupnorm_params`、`dropout_params`（无参数）。

## 5. 用外部权重创建层

从 GGUF / checkpoint 装载或自定义重参数化时：

```cpp
Linear layer{};
linear_init_weight(ctx, &layer, weight_tensor, bias_tensor);   // weight 布局 [in,out]，bias 可为 nullptr
```

对应的 `*_init_weight`：`linear_init_weight`、`embedding_init_weight`、`conv1d_init_weight`、`conv2d_init_weight`、`convtranspose1d_init_weight`、`layernorm_init_weight`、`rmsnorm_init_weight`、`groupnorm_init_weight`。

## 6. 复合模型

本库不提供具体模型结构；用户自定义结构体并组合上述层与算子：

```cpp
struct MyModel {
    Conv1d      c1{}, c2{};
    LayerNorm   ln{};
    Linear      head{};
};

MyModel m;
conv1d_init(ctx, &m.c1, ...);
layernorm_init(ctx, &m.ln, ...);
linear_init(ctx, &m.head, ...);

ParamList params;
conv1d_params(&m.c1, &params);
layernorm_params(&m.ln, &params);
linear_params(&m.head, &params);
```

## 7. 尾部为 1 的维度

最后一维为 1 的合法权重（如 `ConvTranspose1d(Cin=1)`、`Conv1d/Conv2d(OC=1)`、`Linear(out=1)`、`Embedding(dim=1)`）的初始化与前向均正常，初始化按层布局显式计算 fan。
