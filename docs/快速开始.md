# 快速开始

本文用两个可编译的程序走通最短路径：一个前向计算，一个完整训练。构建方式见《构建与集成》。

## 1. 环境

- 支持 C++20 的编译器。
- CMake ≥ 3.20。

## 2. 构建

```sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build --output-on-failure
```

若使用 `CMakePresets.json`：

```sh
cmake --preset release
cmake --build --preset release
ctest --test-dir out/build/release --output-on-failure
```

## 3. 在项目中使用

```cmake
add_subdirectory(<traincpp 路径> traincpp)
target_link_libraries(app PRIVATE traincpp::traincpp)
```

源文件包含总头：

```cpp
#include <traincpp/traincpp.h>
using namespace traincpp;
```

## 4. 第一个程序：前向计算

计算 `y = sigmoid(a * a)`。

```cpp
#include <traincpp/traincpp.h>
#include <cstdio>

using namespace traincpp;

int main() {
    // 上下文：管理张量元数据；默认 no_alloc=true，数据由后端 buffer 分配
    Context* ctx = context_new(1 << 20);
    Graph*   g   = graph_new(ctx);

    Device* dev = device_cpu();

    // 构造张量与计算节点（只是建图，尚未计算）
    Tensor* a = new_tensor_1d(ctx, TYPE_F32, 4);
    Tensor* y = sigmoid(ctx, mul(ctx, a, a));

    // 分配张量数据（必须在使用数据之前；视图也会在此解析）
    Buffer* buf = buffer_alloc_ctx_tensors(ctx, dev->default_buffer_type());

    const float in[4]  = {1.0f, -2.0f, 3.0f, 0.5f};
    float       out[4] = {0};
    tensor_set(a, in, 0, sizeof(in));   // 写入输入（字节偏移 + 字节长度）

    graph_build_forward_expand(ctx, g, y);  // 展开计算图
    dev->graph_compute(g);                  // 执行
    tensor_get(y, out, 0, sizeof(out));     // 读取输出

    for (int i = 0; i < 4; ++i) {
        std::printf("y[%d] = %.6f\n", i, out[i]);
    }

    buffer_free(buf);
    graph_free(g);
    context_free(ctx);
    return 0;
}
```

要点：

- 先建张量与节点，再 `buffer_alloc_ctx_tensors`，最后 `graph_compute`。
- `tensor_set` / `tensor_get` 的偏移与长度以**字节**计。
- 计算图构建完成后不应再新增张量。

## 5. 第一个训练：MLP 回归

用一个两层 MLP 拟合 `y = 2*x0 - 3*x1 + x2 + 0.5*x3 + 1`。

```cpp
#include <traincpp/traincpp.h>
#include <cmath>
#include <cstdio>
#include <vector>

using namespace traincpp;

int main() {
    constexpr int64_t IN = 4, HID = 8, OUT = 1, BATCH = 16;

    Device* dev = device_cpu();
    Context* ctx = context_new(1 << 22);
    Graph*   g   = graph_new(ctx);

    Rng rng;
    rng_seed(&rng, 1234);

    // 1) 模型：Linear(4->8) -> ReLU -> Linear(8->1)
    Linear l1{}, l2{};
    linear_init(ctx, &l1, IN, HID, true, &rng, "fc1");   // *_init 自动标记参数
    linear_init(ctx, &l2, HID, OUT, true, &rng, "fc2");

    ParamList params;
    linear_params(&l1, &params);
    linear_params(&l2, &params);

    // 2) 输入与目标
    Tensor* x      = new_tensor_2d(ctx, TYPE_F32, IN, BATCH);
    Tensor* target = new_tensor_2d(ctx, TYPE_F32, OUT, BATCH);

    // 3) 前向与损失
    Tensor* pred = linear_forward(ctx, &l2, relu(ctx, linear_forward(ctx, &l1, x)));
    Tensor* loss = mse_loss(ctx, pred, target);
    tensor_set_loss(loss);                                // 标记损失

    // 4) 反向展开 -> 分配（顺序不可交换）
    graph_build_forward_expand(ctx, g, loss);
    graph_build_backward_expand(g);
    Buffer* buf = buffer_alloc_ctx_tensors(ctx, dev->default_buffer_type());

    // 5) 优化器（主机端实现，CPU/Vulkan 通用）
    AdamwOptions o;
    o.lr = 0.05f;
    o.weight_decay = 0.0f;
    Optimizer* opt = optim_adamw_new(ctx, params.items.data(), param_list_count(&params), o);

    // 6) 填入数据：y = 2*x0 - 3*x1 + x2 + 0.5*x3 + 1
    std::vector<float> vx((size_t) (IN * BATCH)), vt((size_t) BATCH);
    for (int64_t i = 0; i < BATCH; ++i) {
        const float x0 = std::sin((float) i * 0.7f);
        const float x1 = std::cos((float) i * 0.31f);
        const float x2 = (float) (i % 5) * 0.2f - 0.4f;
        const float x3 = (float) (i % 3) * 0.5f - 0.5f;
        vx[(size_t) (i * IN + 0)] = x0;
        vx[(size_t) (i * IN + 1)] = x1;
        vx[(size_t) (i * IN + 2)] = x2;
        vx[(size_t) (i * IN + 3)] = x3;
        vt[(size_t) i] = 2.0f * x0 - 3.0f * x1 + x2 + 0.5f * x3 + 1.0f;
    }
    tensor_set(x, vx.data(), 0, vx.size() * sizeof(float));
    tensor_set(target, vt.data(), 0, vt.size() * sizeof(float));

    // 7) 训练循环
    for (int step = 0; step < 2000; ++step) {
        graph_reset(g);          // 清零梯度 + 损失播种 1.0（每步必须）
        dev->graph_compute(g);   // 前向 + 反向
        optim_step(opt);         // 更新参数
    }

    float lv = 0.0f;
    graph_reset(g);
    dev->graph_compute(g);
    tensor_get(loss, &lv, 0, sizeof(lv));
    std::printf("final loss = %.6g\n", (double) lv);

    optim_free(opt);
    buffer_free(buf);
    graph_free(g);
    context_free(ctx);
    return 0;
}
```

训练循环的三个固定动作：

1. `graph_reset(g)`：清零梯度累加器并给损失播种 `1.0`。不调用会持续累积梯度。
2. `dev->graph_compute(g)`：一次完成前向与反向。
3. `optim_step(opt)`：主机端参数更新。
