# 损失函数

所有损失输出 F32 标量 `[1]`，可直接 `tensor_set_loss` 并参与 `graph_build_backward_expand`。反向由自动求导给出，无需额外 API。

## 1. MSE 与 L1

```cpp
Tensor* loss = mse_loss(ctx, pred, target);   // mean((pred-target)^2)
Tensor* loss = l1_loss(ctx, pred, target);    // mean(|pred-target|)
tensor_set_loss(loss);
```

- reduction 固定为**全元素均值**，等价 PyTorch `nn.MSELoss()` / `nn.L1Loss()` 的默认 `reduction='mean'`。
- 要求 `pred` 与 `target` 同形状、F32。
- 组合实现（不新增 kernel）。`L1` 在 0 处不可导。

若需要求和 reduction，可自行缩放：`scale(loss, (float) tensor_nelements(pred))`。

## 2. 交叉熵

交叉熵是独立算子（声明在 `trc_ops.h`），语义与 ggml 的 `ggml_cross_entropy_loss` 一致：

```cpp
Tensor* loss = cross_entropy_loss(ctx, logits, target_probs);
tensor_set_loss(loss);
```

- `logits`：F32，形状 `[C, nr, ...]`（最内维为类别维 `ne0`）。
- `target_probs`：与 `logits` **同形状**的概率分布（one-hot 或软标签），F32，最内维连续。
- 输出：F32 标量 `[1]`，值为 `-1/nr · Σ_row Σ_c target·log_softmax(logits)`，其中 `nr = ne1*ne2*ne3`（按行均值）。
- `target` 视为常量，不产生梯度（与 ggml 一致）。

注意：**不支持 PyTorch 风格的整数类别标签**。若数据是类别索引，需先转换为 one-hot / 软标签张量。

## 3. 与 PyTorch 的对照

| 本库 | PyTorch |
|---|---|
| `mse_loss` | `MSELoss(reduction='mean')` |
| `l1_loss` | `L1Loss(reduction='mean')` |
| `cross_entropy_loss` | `CrossEntropyLoss`（但目标必须为同形状概率分布，而非类别索引） |

## 4. 数值特性

- MSE / L1 的归约在 CPU 用 double 累加，Vulkan 用 float 分层归约；超长向量可能有约 `1e-5` 量级差异。
- 交叉熵前向与反向均为专用 kernel；CPU 用 double 累加。
