# 与 ggml 的兼容性

- 兼容目标：**ggml v0.23.0**。
- 原则：数据类型取值、张量内存布局、算子数学语义与 ggml 一致；训练产物（GGUF）可被 ggml 系程序直接加载。
- 与 ggml 的任何差异都记录在本文档。

## 1. 数据类型

`traincpp::Type` 枚举值与 ggml `enum ggml_type` 逐值一致（见 `trc_types.h`）。

| 类型 | 值 | 块大小 | 字节/块 | 本库支持 |
|---|---|---|---|---|
| F32 | 0 | 1 | 4 | 计算 / 存储 |
| F16 | 1 | 1 | 2 | 存储 / 转换（部分算子输入） |
| Q4_0 | 2 | 32 | 18 | 仅 GGUF 读取反量化 |
| Q4_1 | 3 | 32 | 20 | 仅 GGUF 读取反量化 |
| Q5_0 | 6 | 32 | 22 | 仅 GGUF 读取反量化 |
| Q5_1 | 7 | 32 | 24 | 仅 GGUF 读取反量化 |
| Q8_0 | 8 | 32 | 34 | 仅 GGUF 读取反量化 |
| Q8_1 | 9 | 32 | 36 | 仅表项 |
| Q2_K…Q8_K | 10-15 | 256 | 84/110/144/176/210/292 | 仅表项 |
| I8 / I16 / I32 / I64 | 24-27 | 1 | 1/2/4/8 | 存储 / 转换 |
| F64 | 28 | 1 | 8 | 存储 / 转换 |
| BF16 | 30 | 1 | 2 | 存储 / 转换 |

fp16 / bf16 转换算法从 ggml-impl.h 移植（`src/core/trc_float.h`）。

## 2. 张量内存布局

与 ggml 完全一致：

```
ne[0]：最内层维度（行主序逻辑下的一行）
nb[0] = type_size(type)          // 量化类型为单块字节数
nb[1] = nb[0] * (ne[0] / blck_size(type))
nb[i] = nb[i-1] * ne[i-1]
```

约定：

1. `ne[0]` 是最内层维度；`nb` 是字节步长。
2. `tensor_nbytes` 对带步长张量返回**跨度**（最后元素偏移 + 元素大小），不是元素数 × 元素大小。
3. `tensor_set/get` 是**原始缓冲区字节**语义（与 ggml backend tensor get/set 一致）：连续张量可按元素读写；非连续视图必须先用 `cont()` 物化。
4. 视图越界检查使用“最后元素偏移 + 元素大小”的实际跨度（`tensor_last_element_offset + type_size`），因为 `tensor_nbytes` 对非递增步长会低估实际范围。

## 3. 算子语义对照

| 本库函数 | ggml 对应 | 语义 / 形状规则 | 备注 |
|---|---|---|---|
| `add` / `sub` / `mul` / `div` | `ggml_add/_sub/_mul/_div` | 结果形状取 a；b 需可重复到 a（每维相等或为 1） | 广播 |
| `add1` | `ggml_add1` | b 必须 1 个元素 | |
| `scale` | `ggml_scale` | `a*s`，s 存 `op_params[0]` | |
| `scale_bias` | `ggml_scale_bias` | `s*a+b`（标量 s/b） | 组合实现（`scale`+`add1`），数值等价 |
| `neg` / `abs_op` / `sqr` / `sqrt_op` / `exp_op` / `log_op` / `sin_op` / `cos_op` | 同名 ggml 一元算子 | 逐元素 | |
| `clamp` | `ggml_clamp` | `min(max(x,min),max)`，参数存 `op_params` | |
| `relu` / `leaky_relu` / `sigmoid` / `tanh_op` / `silu` | 同名 ggml 一元算子 | 逐元素 | leaky_relu 斜率存 `op_params` |
| `gelu` | `ggml_gelu` | `0.5x(1+tanh(0.79788456(x+0.044715x³)))` | tanh 近似 |
| `gelu_erf` | `ggml_gelu_erf` | `0.5x(1+erf(x/√2))` | |
| `softplus` | `ggml_softplus` | `x>20 ? x : log1p(exp(x))` | 阈值同 ggml |
| `hardswish` | `ggml_hardswish` | `x*clamp(x+3,0,6)/6` | |
| `mul_mat` | `ggml_mul_mat` | `a=[k,m,a2,a3]`、`b=[k,n,b2,b3]` → `[m,n,b2,b3]`；要求 `a.ne0==b.ne0`、`b.ne2%a.ne2==0`、`b.ne3%a.ne3==0`（同 `ggml_can_mul_mat`），平面取 `a` 的平面 `(i2%a2, i3%a3)` | 支持 batch 广播 |
| `sum` / `sum_rows` | `ggml_sum` / `ggml_sum_rows` | 全部和 / 沿 ne0 和，**类型同输入** | |
| `mean` | `ggml_mean` | 沿 ne0 均值，类型 F32 | |
| `norm` | `ggml_norm` | 行内 LayerNorm（有偏方差） | 仅 F32 |
| `rms_norm` | `ggml_rms_norm` | 行内 RMSNorm | 权重由外部 `mul` 施加 |
| `group_norm` | `ggml_group_norm` | **通道维是 ne2**；组大小 `ceil(C/ng)` | 仅 F32 |
| `soft_max` | `ggml_soft_max` | 沿 ne0 数值稳定 softmax | 输入需连续 |
| `soft_max_ext` | `ggml_soft_max_ext` | `softmax(scale*a + slope*mask)`；mask 形状 `[ne0, ≥ne1, 整除, 整除]`；`max_bias>0` 启用 ALiBi | 不支持 sinks |
| `cross_entropy_loss` | `ggml_cross_entropy_loss` | `-1/nr·Σ b·log_softmax(a)`，输出 F32 标量；`nr=ne1*ne2*ne3` | logits 与概率目标同形状；不支持转置输入 |
| `cross_entropy_loss_back` | `ggml_cross_entropy_loss_back` | `(softmax(a)-b)·grad/nr`；target 视为常量 | 仅作反向节点 |
| `get_rows` | `ggml_get_rows` | 查表：表 `[ne0,n_vocab,...]`，索引 I32 | F32/F16 表；无量化 / I32 表 |
| `set_rows` | `ggml_set_rows` | 按行写入，结果与 a 共享内存 | 重复索引未定义行为 |
| `repeat` | `ggml_repeat` | a 可重复到 target（每维相等或 1） | 不支持整数倍广播 |
| `repeat_back` | `ggml_repeat_back` | 沿被重复维求和；要求整除 | 与 ggml 一致 |
| `concat` | `ggml_concat` | 沿 dim 拼接，其余维相同 | dim 存 `op_params` |
| `pad` | `ggml_pad` | 每维末尾补零 | op_params 用 `ggml_pad_ext` 布局 |
| `pad_ext` | `ggml_pad_ext` | 每维左右填充；`PAD_ZERO` / `PAD_REFLECT` | reflect 对齐 `torch F.pad(mode='reflect')`；`op_params[8]` 存 mode（ggml 不用该槽，不影响互操作） |
| `im2col` | `ggml_im2col` | 1D `[KW,IC,OC]`+`[W,IC,N]`；2D `[KW,KH,IC,OC]`+`[W,H,IC,N]` | 输出仅 F32 |
| `conv_1d` / `conv_2d` | `ggml_conv_1d` / `ggml_conv_2d` | 组合：im2col + mul_mat + reshape | **N>1 时 ggml 的 reshape 顺序有误，本库已修正**（见 §4） |
| `col2im_1d` | `ggml_col2im_1d` | `[K*OC,T_in]` → `[T_out,OC]`，`T_out=(T_in-1)*s+K-2*p` | gather 语义 |
| `conv_transpose_1d` | `ggml_conv_transpose_1d` | `[K,Cout,Cin]`、`[T,Cin]` → `[T_out,Cout,1,1]` | 仅 `p0=0`、`d0=1` |
| `pool_2d` | `ggml_pool_2d` | `[W,H,C,N]` → `[OW,OH,C,N]`，`OW=(W+2p0−k0)/s0+1`（floor）；MAX/AVG | AVG 分母恒 `k0*k1`，MAX 跳过越界；p 取 int |
| `pool_2d_back` | `ggml_pool_2d_back` | AVG 均分核面积、MAX 归首个严格最大值 | **仅 CPU**；ggml 同样仅 CPU |
| `conv_transpose_2d` | `ggml_conv_transpose_2d_p0` | `[KW,KH,Cout,Cin]`、`[W,H,Cin,N]` | 仅 stride、`p=0`、`d=1` |
| `cont` | `ggml_cont` | 已连续返回源 | |
| `cast` | `ggml_cast` | 类型相同返回源 | |
| `dup` | `ggml_dup_tensor` | 仅复制元数据 | |
| `view_*` / `reshape_*` / `permute` / `transpose` | 对应 ggml | 视图 / 连续重排 / 置换 | |
| `sgn` / `step` | `ggml_sgn` / `ggml_step` | 符号 / 阶跃 | 反向恒 0 |
| `acc` | `ggml_acc` | 区域累加；op_params `int32[5]`（nb1,nb2,nb3,offset,inplace） | `inplace=true` 结果为 a 的完整视图 |
| `get_rows_back` | `ggml_get_rows_back` | 先清零再 scatter-add | `c` 登记为 `src[2]`（仅形状） |
| `im2col_back` | `ggml_im2col_back` | 对输入的梯度 | 1D 写回步长与 `ofs0/ofs1` 一致 |
| `norm_back` | 无对应 | LayerNorm 反向 | 本库扩展 |
| `rms_norm_back` | `ggml_rms_norm_back` | 公式与 ggml CPU kernel 一致 | |
| `group_norm_back` | 无对应 | 组内套用 LayerNorm 反向 | 本库扩展 |
| `erf_op` | 无对应 | `erf(x)` | 本库扩展（`gelu_erf` 反向用） |

### 3.1 autograd 反向语义

反向通过前向算子组合实现，梯度存 `Tensor::grad` / `grad_acc`。

| 前向 | 反向 |
|---|---|
| `add` | `dA=dY`；`dB=repeat_back(dY, b)`（广播时） |
| `add1` | `dA=dY`；`dB=sum(dY)`（**与 ggml 有意差异**：ggml 用 `mean`，本库取数学正确的 `sum`） |
| `sub` | `dA=dY`；`dB=-dY` |
| `mul` | `dA=dY*b`；`dB=repeat_back(dY*a, b)` |
| `div` | `dA=dY/b`；`dB=-dY*(y/b)` |
| `sqr` / `sqrt` / `exp` / `log` / `sin` / `cos` / `neg` | 组合 |
| `abs` / `sgn` / `step` | `abs: dY*sgn(x)`；`sgn` / `step` 导数为 0 |
| `relu` / `leaky_relu` / `clamp` / `hardswish` | `dY * mask` |
| `sigmoid` / `tanh` / `silu` / `softplus` / `gelu` | 组合 |
| `scale` | `dY*s` |
| `sum` / `sum_rows` / `mean` | `repeat(dY)` / `repeat(dY/ne0)` |
| `mul_mat` | `dA=(dY·Bᵀ)ᵀ`、`dB=Aᵀ·dY`；a 被批量广播时 dA 经 `repeat_back` 归约 |
| `soft_max` | `scale·y·(dY − sum_rows(dY·y))`；mask 为常量 |
| `reshape` / `cont` / `dup` | `cont+reshape` 回源形状 |
| `permute` / `transpose` | 逆置换 |
| `view` | `acc` 区域累加到源 |
| `repeat` | `repeat_back(dY, src0)` |
| `cast` | `cast(dY, src0->type)` |
| `get_rows` | `get_rows_back(dY, indices, table)` |
| `concat` | `cont` + 两段视图切片 |
| `pad` | `cont` + 中心区域裁剪视图 |
| `pad_ext(PAD_REFLECT)` | `pad_back` 专用内核 |
| `im2col` | `im2col_back`（卷积核梯度经 reshape/mul_mat 回流） |
| `conv_transpose_1d` | 组合（im2col + mul_mat） |
| `pool_2d` | `pool_2d_back`（仅 CPU） |
| `conv_transpose_2d` | 组合（im2col + mul_mat + permute） |
| `norm` / `rms_norm` / `group_norm` | 专用反向 kernel |
| `gelu_erf` | `erf` 公式组合 |
| `cross_entropy_loss` | `cross_entropy_loss_back` |

约定：

1. 反向组合所需标量常量由内部创建，`no_alloc=true` 时延迟到分配后写入。
2. PARAM / LOSS 由 `graph_build_backward_expand` 自动创建 F32 `grad_acc`；各贡献通过 inplace `acc` 累加，跨多次 compute 保留（支持梯度累积）。每步 `graph_reset` 清零并把 LOSS 累加器置 1.0。
3. 图构建顺序：前向 → 反向展开 → 分配。
4. 不参与反向：`set_rows`、`cpy`、`out_prod`、`col2im_1d`；`cross_entropy_loss_back`、`pad_back`、`pool_2d_back` 仅作反向结果。
5. 多图共享 / 重复展开在构建期禁止（训练扩展，ggml 无对应语义）。

### 3.2 优化器（训练扩展）

优化器为主机端实现，数值语义对齐 PyTorch `torch.optim.SGD/AdamW`（ggml 无主机端优化器）。ggml 的设备端融合算子 `ggml_opt_step_adamw` / `ggml_opt_step_sgd` 在本库中枚举保留但**未实现**；其元参数布局与公式（AdamW 7 元 / SGD 2 元）与 ggml 对齐，供后续阶段参考。

## 4. 已知差异与约定

1. **Op 枚举数值**：本库自定义顺序（ggml 的数值不进入模型文件）；名称与数学语义对齐。
2. **视图内存归属**：视图永不分配内存；分配时按登记顺序解析视图 `data`（源先于视图创建）。
3. **量化**：仅读取端支持 5 种 legacy 量化反量化；量化类型不参与计算。
4. **计算精度**：计算内核以 F32 为主。
5. **`tensor_get/set` 字节语义**：见 §2。
6. **测试黄金数据格式**：`tests/golden/*.npy` 形状 = ne 反转 `(ne3,ne2,ne1,ne0)`、C 序。
7. **Vulkan 缓冲策略**：host-visible + coherent 常驻映射，`base()` 返回主机指针；默认 host-visible（优化器/梯度清零为主机实现），`TRC_VK_DEVICE_LOCAL=1` 才优先显存。
8. **Vulkan `erf` 近似**：A&S 7.1.26（与 ggml Vulkan 同系数）；CPU 用 `std::erf`。
9. **索引越界**：CPU 与 Vulkan 均中止（Vulkan 经错误缓冲在 compute 末尾 abort）。
10. **Vulkan 归约**：GPU 用 float 分层归约，CPU 用 double；超长行可能有约 1e-5 差异。
11. **Vulkan `mul_mat`**：tiled（BM=BN=64、BK=16），batch 平面放 grid z 并跨步；与 CPU 小规模逐位一致。
12. **`set_rows` 重复索引**：未定义行为，数据须保证索引唯一。
13. **`conv_1d` 在 N>1 时的修正**：ggml 的 `ggml_conv_1d` 组合在批量 N>1 时行序错误；本库 N>1 用 `reshape_3d(r,OW,N,OC) + permute + cont`（N=1 时与 ggml 逐位一致）。
14. **nn 层为训练扩展**：层由已有算子组合，权重布局 = PyTorch `state_dict`；RNG 为自研 splitmix64，与 PyTorch 随机流不同。
15. **MSE/L1 为组合封装**：reduction 固定全元素均值（对齐 PyTorch 默认，不是 ggml `mean` 的 ne0 行内均值）。
16. **`acc` op_params**：与 ggml `ggml_acc_impl` 一致的 `int32[5]`；`inplace=true` 结果为 a 的完整视图。
17. **GGUF 约定**：写 v3、读 v2/v3；张量 dims 按 `ne[0..]` 不反转；仅小端；写端不量化；读端宽容（不要求数据段末尾填充）。
18. **checkpoint**：训练侧自有 schema，容器复用 GGUF；`traincpp.*` 键与 `<param>.opt.*` 状态名不进入 ggml 推理生态。
19. **`pool_2d`**：p0/p1 本库取 int（ggml 形参 float 但写入时截断）；AVG 分母恒 `k0*k1`；MAX 跳过越界。
20. **`conv_transpose_2d` 与 `scale_bias`**：语义与 ggml 对应算子一致；`scale_bias` 为组合实现。

## 5. 未对齐 / 待补齐

- 设备端融合优化器（`opt_step_*`）。
- 量化导出与量化计算。
- `out_prod`、`set_rows` 反向、`col2im_1d` 反向。
- K-quant / IQ 反量化读取。
