# 构建与集成

本文档说明 traincpp 的系统要求、工具链、构建方式，以及作为库被其他程序集成的方式。

## 1. 平台与依赖

| 项目 | 要求 |
|---|---|
| 操作系统 | 核心为可移植 C++20 代码；当前验证平台为 Windows 11。Vulkan 后端在支持 Vulkan 1.2 的系统上可移植；Linux / macOS 未验证。 |
| 编译器 | 支持 C++20 的编译器；当前验证为 MSVC 19.5x（VS2026）。 |
| 构建系统 | CMake ≥ 3.20。推荐使用 Ninja 生成器；其它生成器（如 Visual Studio）同样可用。 |
| Vulkan SDK | 可选。仅当启用 Vulkan 后端时需要，且须包含 `glslc`。 |
| Python + PyTorch | 可选。仅用于重新生成测试数据（`tests/golden`）。构建与运行不需要。 |

库本体不引入任何第三方运行时依赖。Vulkan 后端直接链接系统 Vulkan 加载器，shader 在构建期由 `glslc` 编译并嵌入库中。

## 2. 使用 CMake 构建

单配置生成器（Ninja、Makefiles）：

```sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

多配置生成器（Visual Studio）：

```sh
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

## 3. CMake 预设

仓库提供 `CMakePresets.json`，包含：

| 预设 | 生成器 | 说明 |
|---|---|---|
| `release` | Ninja | Release；Vulkan 后端自动探测 |
| `release-cpu` | Ninja | Release；关闭 Vulkan 后端（`TRC_VULKAN=OFF`） |
| `debug` | Ninja | Debug；Vulkan 后端自动探测 |

用法：

```sh
cmake --preset release
cmake --build --preset release
ctest --test-dir out/build/release --output-on-failure
```

预设需要 CMake ≥ 3.20。使用预设时请确保 Ninja 与 C++20 编译器位于 `PATH`。

## 4. CMake 选项

| 选项 | 默认 | 说明 |
|---|---|---|
| `TRC_CPU` | `ON` | 启用 CPU 参考后端。 |
| `TRC_VULKAN` | `ON` | 启用 Vulkan 后端。找不到 Vulkan SDK 时自动关闭并给出警告。 |
| `TRC_BUILD_TESTS` | `ON` | 构建测试。 |
| `TRC_BUILD_EXAMPLES` | `ON` | 构建示例程序。 |
| `TRC_INSTALL` | `ON` | 生成安装规则与 `find_package` 配置。 |

示例：仅构建库与 CPU 后端，不构建测试与示例：

```sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release \
      -DTRC_VULKAN=OFF -DTRC_BUILD_TESTS=OFF -DTRC_BUILD_EXAMPLES=OFF
cmake --build build
```

## 5. Vulkan 后端探测

- 配置阶段调用 `find_package(Vulkan COMPONENTS glslc)`。
- 未找到 SDK 时打印警告并自动设置 `TRC_VULKAN=OFF`，不中止配置。
- SDK 位置可通过环境变量 `VULKAN_SDK` 指定；也可显式 `-DTRC_VULKAN=OFF` 跳过探测。
- 运行期无可用 Vulkan 设备时，设备接口返回空指针，相关测试自动跳过，不中止进程。

## 6. 构建产物

- 库与可执行文件统一输出到构建目录下的 `bin/` 与 `lib/`。
- 使用预设时构建目录为 `out/build/<preset>`。

## 7. 运行测试

```sh
ctest --test-dir build --output-on-failure
```

- 使用多配置生成器时需指定配置：`ctest --test-dir build -C Release --output-on-failure`。
- 部分测试依赖 `tests/golden` 的参考数据；仓库已包含这些数据，无需额外生成。
- 指定计算设备：环境变量 `TRC_TEST_DEVICE=cpu|vulkan`（默认 `cpu`）。CTest 中已有在 Vulkan 上复跑的用例；无设备时自动跳过。
- 重新生成参考数据（需要 PyTorch）：`python scripts/gen_golden.py`。

## 8. 作为库集成

### 8.1 源码内嵌（`add_subdirectory`）

```cmake
add_subdirectory(<traincpp 路径> traincpp)
target_link_libraries(<你的目标> PRIVATE traincpp::traincpp)
```

### 8.2 安装后 `find_package`

```sh
cmake --install build --prefix <安装目录>
```

```cmake
find_package(traincpp CONFIG REQUIRED)
target_link_libraries(<你的目标> PRIVATE traincpp::traincpp)
```

可按需只链接部分组件：

| 目标 | 内容 |
|---|---|
| `traincpp::traincpp` | 聚合目标（含已启用的全部后端） |
| `traincpp::core` | 核心（张量、图、autograd、nn、loss、optim、I/O） |
| `traincpp::cpu` | CPU 参考后端 |
| `traincpp::vulkan` | Vulkan 后端 |

### 8.3 集成注意事项

- 使用方需支持 C++20。
- 公共头为 `#include <traincpp/trcXXX.h>`，或包含总头 `#include <traincpp/traincpp.h>`。
- 公共头含 UTF-8 中文注释；MSVC 下 `/utf-8` 通过 CMake `INTERFACE` 属性自动传播到使用方。
- 库不需要显式初始化；首次调用设备接口时自动完成注册。
- 以 `find_package` 集成且构建时启用了 Vulkan 时，`traincpp-config.cmake` 会调用 `find_dependency(Vulkan)`，使用方环境需能定位 Vulkan。

## 9. 源码字符集

源文件与公共头统一使用 UTF-8 编码。非 MSVC 编译器一般默认按 UTF-8 处理；如遇编码问题，请为编译器显式指定输入字符集为 UTF-8。
