# 算子参考

算子以自由函数形式创建，输入张量、返回新的张量节点。返回的节点需要加入计算图（`graph_build_forward_expand`）后才会在 `graph_compute` 时求值。

## 1. 通用约定

- 构造算子不会立即计算，只建立节点；张量数据在 `buffer_alloc_ctx_tensors` / `buffer_alloc_graph_tensors` 时分配。
- 计算内核以 **F32** 为主。个别算子允许 F16 作为输入（见第 2 节支持矩阵）。
- 视图类算子（`view_*` / `reshape_*` / `permute` / `transpose` / `cont` 返回源时）不拥有内存，数据指向源张量。
- `tensor_set` / `tensor_get` 为字节语义；非连续视图需先 `cont()` 物化。
- 逻辑广播：`add` / `sub` / `mul` / `div` 要求第二个操作数每维等于 1 或等于第一个操作数的对应维（`tensor_can_repeat`）。
- `mul_mat` 的批量广播：`a=[k,m,a2,a3]`、`b=[k,n,b2,b3]`，要求 `b.ne[2] % a.ne[2] == 0`、`b.ne[3] % a.ne[3] == 0`，平面 `(i2,i3)` 使用 `a` 的平面 `(i2 % a2, i3 % a3)`。
- `ne[0]` 是最内层维度（与 ggml 一致）。

算子是否可在某后端执行，用 `Device::supports_op` 查询，或用 `graph_first_unsupported(graph, dev)` 在整图上预检。

## 2. 支持矩阵

- “支持”表示语义与 CPU 一致。
- 未列出的算子组合在对应后端不可用，会明确中止。

| 类别 | 算子 | CPU | Vulkan | 主要约束 |
|---|---|---|---|---|
| 元数据 | `dup` | 支持 | 支持 | Vulkan 仅同类型 F32 |
| 形状 | `view_1d..4d`、`reshape_1d..4d`、`permute`、`transpose` | 支持 | 支持 | 视图不拥有内存；`reshape` 要求源连续 |
| 形状 | `cont` | 支持 | 支持 | 已连续则返回源 |
| 类型 | `cast` | 支持 | 受限 | CPU：8 种基本类型互转；Vulkan：仅 F32↔F16，且需设备 16 位存储 |
| 逐元素二元 | `add`、`sub`、`mul`、`div` | 支持 | 支持 | F32；b 需可广播 |
| 逐元素二元 | `add1` | 支持 | 支持 | b 为 1 元素标量 |
| 逐元素一元 | `neg`、`abs_op`、`sqr`、`sqrt_op`、`exp_op`、`log_op`、`sin_op`、`cos_op`、`clamp`、`sgn`、`step` | 支持 | 支持 | F32 |
| 激活 | `relu`、`leaky_relu`、`sigmoid`、`tanh_op`、`silu`、`gelu`、`gelu_erf`、`erf_op`、`softplus`、`hardswish` | 支持 | 支持 | F32 |
| 缩放 | `scale`、`scale_bias` | 支持 | 支持 | F32；s/b 为标量 |
| 归约 | `sum`、`sum_rows` | 支持 | 支持 | 结果类型同输入（计算 F32）；`mean` 固定 F32 |
| 归约 | `mean` | 支持 | 支持 | 沿 ne0 |
| 归一化 | `norm`、`rms_norm`、`group_norm` | 支持 | 支持 | F32；`group_norm` 沿 ne2 分组 |
| 归一化反向 | `norm_back`、`rms_norm_back`、`group_norm_back` | 支持 | 支持 | 入参 `(dy, x)`，形状同 x |
| 注意力 | `soft_max` | 支持 | 支持 | 输入需连续 |
| 注意力 | `soft_max_ext` | 支持 | 受限 | mask 形状 `[ne0, ≥ne1, 整除, 整除]`；CPU mask 可 F32/F16，**Vulkan 仅 F32** |
| 索引 | `get_rows` | 支持 | 受限 | 表 CPU F32/F16、**Vulkan 仅 F32**；索引 CPU I32/I64、**Vulkan 仅 I32** |
| 索引 | `get_rows_back` | 支持 | 支持 | 索引仅 I32；CPU 要求目标连续 |
| 索引 | `set_rows` | 支持 | 受限 | 值 CPU F32/F16、**Vulkan 仅 F32**；索引 CPU I32/I64、**Vulkan 仅 I32**；**重复索引为未定义行为** |
| 形状扩展 | `repeat`、`repeat_back` | 支持 | 支持 | Vulkan 仅 F32；`repeat` 要求每维相等或为 1，`repeat_back` 要求整除 |
| 形状扩展 | `concat` | 支持 | 支持 | Vulkan 仅 F32；非拼接维必须相同 |
| 形状扩展 | `pad`、`pad_ext` | 支持 | 支持 | 支持零填充与 reflect；reflect 要求每侧填充量 < 对应维长度 |
| 形状扩展 | `pad_back` | 支持 | 支持 | 仅作 reflect 反向 |
| 形状扩展 | `acc` | 支持 | 支持 | F32；CPU 要求连续；`inplace` 区域累加 |
| 卷积 | `im2col` | 支持 | 受限 | 输出 F32；图像 CPU F32/F16、**Vulkan 仅 F32** |
| 卷积 | `im2col_back` | 支持 | 支持 | F32，需连续 |
| 卷积 | `conv_1d`、`conv_2d` | 支持 | — | 组合图（无独立节点）；见下 |
| 卷积 | `col2im_1d` | 支持 | 支持 | F32，输入 2D 连续 |
| 转置卷积 | `conv_transpose_1d` | 支持 | 支持 | 仅 `p0=0`、`d0=1`；`b` 为 2D |
| 转置卷积 | `conv_transpose_2d` | 支持 | 支持 | 仅 stride、`p=0`、`d=1` |
| 池化 | `pool_2d` | 支持 | 支持 | MAX/AVG；`p0/p1` 取整 |
| 池化 | `pool_2d_back` | 支持 | **不支持** | 仅 CPU |
| 线代 | `mul_mat` | 支持 | 支持 | F32；批量广播见 §1 |
| 损失 | `cross_entropy_loss`、`cross_entropy_loss_back` | 支持 | 支持 | F32、同形状、最内维连续 |

说明：`conv_1d` / `conv_2d` 由已有算子组合展开（`im2col + mul_mat + reshape/permute`），因此没有单独的节点类型；其组成算子在两后端均受支持。

## 3. 逐类用法

### 3.1 形状与视图

```cpp
// 视图：沿用源的步长，数据 = 源数据 + offset（字节）
Tensor* v = view_2d(ctx, a, /*ne0=*/4, /*ne1=*/8, /*offset=*/0);

// reshape：要求源连续，元素数不变（共享数据）
Tensor* r = reshape_2d(ctx, a, 32, 1);

// 置换与转置（按 4 维创建）
Tensor* p = permute(ctx, a, 1, 0, 2, 3);
Tensor* t = transpose(ctx, a);

// 物化连续（已连续则返回源）
Tensor* c = cont(ctx, p);

// 类型转换（类型相同则返回源）
Tensor* h = cast(ctx, a, TYPE_F16);
```

要点：对非连续视图直接 `tensor_get` 得到的是底层缓冲区线性字节；需要按元素读时必须先 `cont()`。

### 3.2 逐元素与激活

```cpp
Tensor* s  = add(ctx, a, b);           // b 可广播到 a
Tensor* s2 = mul(ctx, a, scalar);      // 标量需先建 1 元素张量
Tensor* r  = relu(ctx, a);
Tensor* g  = gelu(ctx, a);
Tensor* sc = scale(ctx, a, 0.5f);      // a * 0.5
Tensor* af = scale_bias(ctx, a, 2.0f, 1.0f);  // 2*a + 1
Tensor* cl = clamp(ctx, a, -1.0f, 1.0f);
```

`scale_bias` 为组合实现（`scale` + `add1`），自动反传。

### 3.3 归约与归一化

```cpp
Tensor* total = sum(ctx, a);        // [1]
Tensor* rows  = sum_rows(ctx, a);   // [1, ne1, ne2, ne3]
Tensor* m     = mean(ctx, a);       // F32

Tensor* n  = norm(ctx, a, 1e-5f);             // 行内 LayerNorm
Tensor* rn = rms_norm(ctx, a, 1e-5f);         // 行内 RMSNorm
Tensor* gn = group_norm(ctx, a, /*n_groups=*/8, 1e-5f);  // 沿 ne2 分组
```

归一化的仿射（weight/bias）由 nn 层在外部施加；直接使用算子时需自行 `mul` / `add`。

### 3.4 softmax

```cpp
Tensor* sm = soft_max(ctx, logits);                         // 沿 ne0
// 带缩放与 mask（ALiBi：max_bias > 0）
Tensor* sm2 = soft_max_ext(ctx, logits, mask, /*scale=*/1.0f / std::sqrt((float) d), /*max_bias=*/0.0f);
```

`soft_max_ext` 的输入与 mask 需连续；mask 形状见支持矩阵。

### 3.5 索引

```cpp
// Embedding 查表：indices 为 I32
Tensor* emb = get_rows(ctx, table, indices);

// 按行写入（结果与 target 共享内存）；indices 唯一
Tensor* updated = set_rows(ctx, target, values, indices);
```

`set_rows` 对重复索引的写入顺序不确定（CPU 顺序覆盖、并行后端竞态），训练数据必须保证索引唯一。

### 3.6 形状扩展

```cpp
Tensor* rep = repeat(ctx, a, target_shape_tensor);
Tensor* cat = concat(ctx, a, b, /*dim=*/1);
Tensor* zp  = pad(ctx, a, 1, 1, 0, 0);                 // 每维末尾补零
Tensor* rf  = pad_ext(ctx, a, 1, 1, 1, 1, 0, 0, 0, 0,
                      PAD_REFLECT);                    // 镜像反射
```

`pad_ext` 每维左右分别填充；reflect 模式要求每侧填充量小于对应维长度。

### 3.7 卷积

```cpp
// 1D 卷积：w=[KW,IC,OC]，x=[W,IC,N] -> [OW,OC,N]
Tensor* y1 = conv_1d(ctx, w1, x1, /*s0=*/1, /*p0=*/0, /*d0=*/1);

// 2D 卷积：w=[KW,KH,IC,OC]，x=[W,H,IC,N] -> [OW,OH,OC,N]
Tensor* y2 = conv_2d(ctx, w2, x2, 1, 1, 0, 0, 1, 1);

// 底层展开（通常不直接调用，卷积内部使用）
Tensor* col = im2col(ctx, w1, x1, 1, 0, 0, 0, 1, 0, /*is_2d=*/false, TYPE_F32);
```

日常训练应使用《神经网络层》中的 `conv1d_forward` / `conv2d_forward`，它们负责权重布局、偏置与批量维度。

### 3.8 线性代数

```cpp
// a=[k,m]，b=[k,n] -> [m,n]
Tensor* y = mul_mat(ctx, a, b);

// 批量：[k,m,a2,a3] * [k,n,b2,b3] -> [m,n,b2,b3]
Tensor* yb = mul_mat(ctx, A, B);
```

### 3.9 损失

```cpp
Tensor* ce = cross_entropy_loss(ctx, logits, target_probs);  // F32 标量；target 为概率分布
```

实际训练中通常使用《损失函数》中的 `mse_loss` / `l1_loss`，以及把 `cross_entropy_loss` 直接作为损失节点。

## 4. 反向支持

反向由自动求导组合得出，无需为每个前向单独调用。已支持反向的前向算子见于《自动求导与训练》；以下算子不参与反向：`set_rows`、`cpy`、`out_prod`、`col2im_1d`，以及 `pad_back` / `pool_2d_back` / `cross_entropy_loss_back` 等仅作反向结果使用的节点。
