# 自动求导与训练

train.cpp 的反向传播是**前向算子的组合**，反向节点追加进同一 `Graph`；一次 `graph_compute` 同时完成前向与反向。

## 1. 基本流程

```cpp
tensor_set_param(w);          // 标记可训练参数（无输入叶子张量）
tensor_set_loss(loss);        // 标记损失（F32 标量）

graph_build_forward_expand(ctx, g, loss);   // 1) 前向展开
graph_build_backward_expand(g);             // 2) 反向展开（必须在分配之前）
Buffer* buf = buffer_alloc_ctx_tensors(ctx, dev->default_buffer_type());  // 3) 分配

for (int step = 0; step < n; ++step) {
    tensor_set(x, ...);       // 刷新输入
    graph_reset(g);           // 4) 清零梯度 + 损失播种 1.0
    dev->graph_compute(g);    //    前向 + 反向
    optim_step(opt);          // 5) 参数更新
}
```

顺序固定：前向 → 反向展开 → 分配 → 每步 `graph_reset` + compute。图构建完成后不可再新增张量。

## 2. 梯度语义

- 参数与损失的梯度存放在 `Tensor::grad` / `grad_acc`；`graph_build_backward_expand` 会为每个 `PARAM` 与 `LOSS` 自动创建 F32 累加器。
- 梯度以 **inplace 累加**方式写入持久累加器：同一窗口内多次 compute 会持续累积。
- `graph_reset(g)`：清零所有累加器，并把损失的累加器置 `1.0`。**每个训练步必须调用**。
- `graph_reset_accumulate(g)`：只把损失累加器置 `1.0`，不清零其它累加器，用于 micro-batch 梯度累积。

读取梯度：

```cpp
Tensor* gw = graph_get_grad(g, w);   // 等价于 w->grad，指向 grad_acc
```

## 3. 梯度累积（micro-batch）

```cpp
graph_reset(g);                          // 窗口开始：清零 + 播种
for (int k = 0; k < K; ++k) {
    graph_reset_accumulate(g);           // 只播种（重复调用无副作用）
    tensor_set(x, micro_x[k]);
    tensor_set(target, micro_t[k]);
    dev->graph_compute(g);
}
optim_clip_grad_norm(opt, 1.0f);         // 可选
optim_step(opt);
```

累积结果是 K 个 micro-batch 梯度之**和**。若原始损失是批均值、且希望累积等价于全批量均值，需要把每个 micro-batch 的损失缩放 `1/K`（例如 `scale(loss, 1.0f / K)`）。

## 4. 梯度裁剪

```cpp
float pre_norm = optim_clip_grad_norm(opt, /*max_norm=*/1.0f);
```

全局 L2 范数裁剪，返回裁剪前的总范数；语义同 `torch.nn.utils.clip_grad_norm_`。

## 5. 冻结与解冻

```cpp
param_list_set_param(&params, false);   // 冻结：下一次反向展开不建立这些参数的梯度
param_list_set_param(&params, true);    // 解冻
tensor_clear_param(t);                  // 单张量取消标记
```

冻结/解冻只影响**下一次** `graph_build_backward_expand`；已构建反向的图不会撤销既有累加器。

## 6. 多图与双网络训练

同一 `Context` 中，一个参数（或反向梯度路径上的中间量）只能属于一个已构建反向的图；检测到共享会在构建期中止。同一 `Graph` 也不可重复展开反向。`graph_free` / `graph_clear` 会释放归属。

双网络（如 GAN 的生成器 G 与判别器 D）的标准协议是**冻结/解冻 + detach 输入**：

```cpp
// G 图：G(z) -> D_frozen(fake) -> G 损失（D 参数冻结，不建 D 的梯度）
Tensor* fake   = generator_forward(ctx, z);
Tensor* g_loss = ...;                                 // 其中调用判别器前向
tensor_set_loss(g_loss);
param_list_set_param(&d_params, false);               // 冻结 D
graph_build_forward_expand(ctx, g_graph, g_loss);
graph_build_backward_expand(g_graph);

// D 图：D(real) / D(fake) -> D 损失（G 冻结 => fake 视为常量，等价 detach）
param_list_set_param(&d_params, true);
param_list_set_param(&g_params, false);               // 冻结 G
Tensor* d_loss = add(ctx,
                     mse_loss(ctx, discriminator_forward(ctx, real), t_real),
                     mse_loss(ctx, discriminator_forward(ctx, fake), t_fake));
tensor_set_loss(d_loss);
graph_build_forward_expand(ctx, d_graph, d_loss);
graph_build_backward_expand(d_graph);
param_list_set_param(&g_params, true);                // 恢复（只影响后续展开）

Buffer* buf = buffer_alloc_ctx_tensors(ctx, dev->default_buffer_type());  // 两图一次分配

for (int step = 0; step < steps; ++step) {
    graph_reset(g_graph); dev->graph_compute(g_graph); optim_step(g_opt);
    graph_reset(d_graph); dev->graph_compute(d_graph); optim_step(d_opt);
}
```

要点：

- 两个训练步要成对按序执行，且各自 compute 前必须 `graph_reset`。
- 两个图可分别使用各自的优化器与调度器。
- 更多上下文见《优化器与调度》与《示例程序》。

## 7. 训练步序与 Dropout

`Dropout` 的 mask 是图内延迟创建的叶子张量。启用 dropout 时，每个训练步的顺序为：

```cpp
graph_reset(g);
dropout_refresh(&drop, &rng);   // 重新采样 mask（必须在 compute 之前）
dev->graph_compute(g);
```

评估时 `dropout_set_training(&drop, false)`，前向直接返回输入。

## 8. 反向覆盖情况

已实现反向的算子（由 autograd 组合或专用反向 kernel）：

- 形状/移动：`dup`、`cont`、`reshape`、`view`、`permute`、`transpose`、`cast`
- 逐元素：`add`、`add1`、`sub`、`mul`、`div`、`neg`、`abs_op`、`sqr`、`sqrt_op`、`exp_op`、`log_op`、`sin_op`、`cos_op`、`clamp`、`scale`
- 激活：`relu`、`leaky_relu`、`sigmoid`、`tanh_op`、`silu`、`softplus`、`hardswish`、`gelu`、`gelu_erf`
- 归约：`sum`、`sum_rows`、`mean`
- 形状扩展：`repeat`、`repeat_back`、`concat`、`pad`
- 线代与注意力：`mul_mat`、`soft_max`
- 索引：`get_rows`
- 卷积：`im2col`、`conv_transpose_1d`、`conv_transpose_2d`、`pool_2d`
- 归一化：`norm`、`rms_norm`、`group_norm`
- 损失：`cross_entropy_loss`

不参与反向的算子：`set_rows`、`cpy`、`out_prod`、`col2im_1d`、`acc`；`pad_back`、`pool_2d_back`、`cross_entropy_loss_back` 仅作反向结果，不支持二次反向。`pool_2d_back` 仅在 CPU 可用。

## 9. 常见构建期错误

- 未标记参数：`没有可训练参数：请先调用 tensor_set_param`
- 未标记损失：`没有损失：请先调用 tensor_set_loss`
- 重复反向展开：同一 Graph 已构建过反向，需 `graph_clear` 或新建 Graph
- 多图共享：参数或梯度路径中间量属于另一张已构建反向的图
- 图未覆盖：图级分配时某待分配张量不在图中

详细消息与排查见《问题排查》。
